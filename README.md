## The entry

> The dish sponge: soaks up everyone else's mess all week, then gets thrown away for smelling like the job.

105 characters, one line. The dish sponge is about as boring and everyday as
an object gets — it lives by the sink and nobody notices it until it smells.
The joke comes from how it really behaves: it spends its life soaking up
everyone else's mess, and the moment it starts to smell like the work it did,
it gets thrown in the bin. The sponge is fired for doing exactly what it was
hired to do.

## How it works

`main.py` (Python 3) writes the review deterministically to
`/output/entry.txt` and validates the competition gate first: UTF-8 text,
1–200 characters, a single line, not only whitespace.

```sh
python3 main.py
cat /output/entry.txt
```
